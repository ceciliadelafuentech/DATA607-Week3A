Overview

For Assignment 3A, to implement a Global Baseline Estimator, I will first look at the formula provided in the Excel sheet. The formula is Global Baseline Estimate = Mean Movie Rating + A movie’s rating relative to average + A respondent’s rating relative to average. The plan is to first establish the average rating across all movies and survey respondents, which if I remember correctly, I had already calculated in Assignment 2A, then each movie’s rating relative to average and each respondent’s rating relative to average. From here I can estimate the rating a particular user would give a movie, and if they have rated them I can compare their actual rating with the estimate.

global_mean <- mean(movie_data$rating, na.rm = TRUE)
global_mean
[1] 4.105263
movie_effect <- movie_data %>%
  group_by(movie) %>%
  summarise(
    movie_mean = mean(rating, na.rm = TRUE)
  )
movie_effect <- movie_effect %>%
  mutate(
    movie_relative = movie_mean - global_mean
  )
user_effect <- movie_data %>%
  group_by(id) %>%
  summarise(
    user_mean = mean(rating, na.rm = TRUE)
  )
user_effect <- user_effect %>%
  mutate(
    user_relative = user_mean - global_mean,
    user_relative = ifelse(is.nan(user_relative), 0, user_relative)
  )
baseline_data <- movie_data %>%
  left_join(
    movie_effect %>% select(movie, movie_relative),
    by = "movie"
  ) %>%
  left_join(
    user_effect %>% select(id, user_relative),
    by = "id"
  )
baseline_data <- baseline_data %>%
  mutate(
    baseline_estimate = global_mean + movie_relative + user_relative,
    baseline_estimate = pmin(baseline_estimate, 5)
  )
recommendations <- baseline_data %>%
  filter(is.na(rating)) %>%
  arrange(id, desc(baseline_estimate))
